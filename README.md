# About
<b>Super BlueBird 64</b> is the fully realized version of <b>Blue Bird 64</b>, originally made in 2 days.

### Development
[Blue Bird 64](https://github.com/SnowmanSixtyFour/BlueBird64)'s original gameplay loop featured a spin on the classic Flappy Bird gameplay loop, with a full 3D environment and a movable camera.

Then, [Blue Bird 64 x2](https://github.com/SnowmanSixtyFour/BlueBird64-x2) introduced online support, with lobbies hosted via Unity's [Lobby](https://docs.unity.com/en-us/lobby) service.
